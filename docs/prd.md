# Product Requirements Document — Vertexon LMS-AI v1.0

## Executive Summary
Vertexon Learning Technologies is building an AI-augmented Learning Management System (LMS-AI) combining conventional video course delivery and assessments with an embedded RAG AI Tutor.

## Key Features
- **Student Workspace**: Registration/Login, Course Catalog, Video Player, AI Tutor Sidebar, Notes, Bookmarks, Quizzes, Assignments, Certificates, Streaks, Badges.
- **Instructor Workspace**: Analytics Dashboard (lecture drop-off, quiz performance), Course Authoring Wizard, AI Quiz Generator & Reviewer, Assignment Grading.
- **Admin Workspace**: Platform Overview Metrics (DAU, Revenue, Enrollments), User Management & Role Assignment, Course Approval Queue, Content Moderation.

## User Personas
1. **Ananya (Student)**: Needs immediate doubt resolution at night with source citations.
2. **Rohit (Instructor)**: Author of DSA and ML courses, needs automated quiz creation and drop-off analytics.
3. **Meera (Admin)**: Manages platform health, course approvals, and user accounts.
